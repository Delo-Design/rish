SSH панель конфигурации и установки web сервера 

Официальный сайт RISH https://rish.su

Протестировано на AlmaLinux 8,9,10 (CentOS 8) и Rocky Linux

Для установки RISH на RHEL 10 и совместимые дистрибутивы (AlmaLinux 10, Rocky Linux 10) с архитектурой `x86_64` процессор должен поддерживать уровень инструкций **x86-64-v3 или выше**. Это требование пакетов PHP из Remi и MariaDB из внешнего репозитория, используемых RISH.

AlmaLinux 10 имеет отдельную сборку `x86_64_v2` для процессоров без поддержки v3. Сама ОС и её штатная MariaDB могут работать на таком процессоре, однако текущая установка RISH с PHP из Remi для EL10 несовместима с ним. Используйте AlmaLinux 9 либо VPS с поддержкой x86-64-v3.

На VPS важен набор инструкций, доступный **внутри виртуальной машины**: гипервизор может ограничивать возможности физического процессора. Количество vCPU не определяет поддержку x86-64-v3.

В начале `ri.sh` показываются модель CPU, архитектура и доступный уровень инструкций. На EL10/x86_64 установка останавливается до изменения конфигов, записи состояния шагов и установки пакетов, если поддержка v3 отсутствует или её не удалось определить.

Проверить доступные уровни инструкций можно командой:

    /lib64/ld-linux-x86-64.so.2 --help

В разделе `Subdirectories of glibc-hwcaps directories` уровень `x86-64-v3` или `x86-64-v4` должен иметь пометку `supported`.

* http/2
* gzip and brotli компрессия

* mpm event для apache
* MariaDB 10.11, 11.4, 11.8 или 12.3
* Система не устанавливает никаких дополнительных сервисов и не расходует попусту ресурсов сервера
* Все актуальные версии PHP начиная с 7.4 (список держится в актуальном состоянии)
* Есть возможность установки Joomla
* Есть возможность выбора версии PHP для каждого сайта на сервере 

Команда установки

Предпочтительная команда установки с основного сервера:

    curl -L get.rish.su | sh && /root/rish/ri.sh

Если у вас блокируется установка с серверов РФ – воспользуйтесь альтернативным адресом. Установка произойдет с серверов github. Альтернативная команда установки:
    
    curl -L getrish.sovmart.com | sh && /root/rish/ri.sh

Внимание! Запускать скрипт надо от root!

Возможно, что в минимальной установке CentOS будет отсутствовать команда curl и ее понадобится установить отдельно:

    yum install curl
